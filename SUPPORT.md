# Support

- **Questions & ideas:** open a GitHub Discussion or an issue using the
  templates in this repo.
- **Bugs:** use the bug report template — include your OS, Node version,
  the command you ran, and its full output.
- **New design system requests:** open a feature request describing the
  product type and the feeling you want (with 1–2 reference sites).

Please search existing issues before opening a new one. This is a
community-maintained project; responses are best-effort.
