# Changelog

All notable changes to this project are documented here.
Format follows Keep a Changelog; versioning follows SemVer.

## [1.0.0] — 2026-11-01

### Added
- Six complete DESIGN.md design systems: aurora-glass, obsidian-fintech,
  paper-editorial, neo-brutal, mint-clinic, terminal-dev.
- Zero-dependency Node CLI: `list`, `add <name>` (safe installer, never
  overwrites), and `validate` (single file or `--all`).
- DESIGN.md completeness validator with a passing test suite (Node's
  built-in test runner).
- Live preview gallery (`preview/index.html`): one self-contained HTML file
  that re-skins the same UI with all six systems.
- Full project scaffolding: CI workflow, issue/PR templates, Dependabot,
  Code of Conduct, Security and Support docs, user guides and prompt
  examples.
